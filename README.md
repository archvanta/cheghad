# CHEGHAD | چقدر؟
نسخه تکمیل‌شده بر مبنای ZIP ارسالی کاربر؛ داده مالی پیش‌فرض ندارد. درآمدهای مورد انتظار از نقد واقعی جدا هستند و خرید/فروش طلا و دلار مستقل محاسبه می‌شوند.

## اجرا
Node.js 24:
```sh
npm ci
npm run dev
npm run check
```
برای خروجی Pages:
```sh
GITHUB_PAGES=true npm run build
GITHUB_PAGES=true npm run preview
```

ثبت درآمد، هزینه یا قسط از بخش مربوط انجام می‌شود؛ «ثبت پرداخت/دریافت» رویداد واقعی است. مبلغ خالی نامعلوم است. موجودی افتتاحیه مربوط به قبل از همه پرداخت‌هاست. تنظیم نرخ دارایی، نقد اولیه، ذخیره و بودجه از تنظیمات انجام می‌شود. اطلاعات در IndexedDB می‌مانند؛ JSON خصوصی را برای پشتیبان دریافت کنید.

## مقایسه تصمیم مالی
در شبیه‌ساز، مبلغ تصمیم امروز و بودجه نگهداری ماهانه را انتخاب کنید. جدول سه ماه آینده، خرید از درآمد، کسری‌ها و ارزش طلای قابل نگهداری را برای خرید طلا و تسویه بدهی مقایسه می‌کند. قیمت ثابت و کارمزد صفر فرض شده؛ داده واقعی تغییر نمی‌کند. هزینه زندگی داخل بودجه نگهداری حساب می‌شود. بدهی خارج از افق هم در خالص دارایی کسر می‌شود.

## هوش مصنوعی
طبق درخواست کاربر فعلاً از رابط و تنظیمات کنار گذاشته شده است. کد قبلی سرور برای بررسی آینده نگهداری شده و منتشر نمی‌شود. هیچ اتصال زنده‌ای فعال نیست.

۳۸ تست مالی/ذخیره‌سازی/امنیت و build اجرا شده‌اند. تست مرورگر دسکتاپ و موبایل با `npm run test:e2e` اجرا می‌شود؛ برای Chromium در صورت نیاز `npx playwright install chromium` را اجرا کنید. تست‌های مقایسه اعداد دو تصویر مرجع را بازتولید می‌کنند. تست‌های سرور با Gemini شبیه‌سازی‌شده‌اند. فایل CODEX_NEXT شرح درخواست اولیه است؛ آخرین دستور کاربر بر آن مقدم است. وضعیت جاری در PROGRESS.md است.

## رابط Finance Bento
داشبورد طبق تصویر و کد مرجع کاربر، به فارسی و RTL با کارت‌های گرادیانی و نمایش مستقل طلا و دلار پیاده شده است. کامپوننت تایپ‌شده در `src/components/ui/finance-bento.tsx` و استایل آن کنار همان فایل است. نسخه سازگار با React/Vite فعلی از CSS معمولی و Recharts موجود استفاده می‌کند و به نصب shadcn یا Tailwind نیازی ندارد. داده‌های دمو، نرخ تبدیل ثابت USD/EUR، بازده فرضی و شکل‌های تصادفی مرجع وارد محصول نشده‌اند.

نمودار دارایی از رویدادهای ثبت‌شده و نرخ دستی فعلی استفاده می‌کند و تاریخچه قیمت بازار نیست. پرداخت‌های آینده، نقد واقعی نیستند. خالص دارایی، بدهی‌های ثبت‌شده خارج از افق را هم کسر می‌کند؛ بدهی تکراری بدون پایان یا نرخ نامعلوم، نتیجه را نامشخص می‌کند. هدف ذخیره از تنظیمات قابل تعیین است.
