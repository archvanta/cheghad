# کیفیت و محدودیت‌های شناخته‌شده

## دامنه بررسی

- تست واحد: پول و ورودی فارسی/عربی، تاریخ کبیسه، تکرار، حقوق آینده، عدم دوباره‌شماری دریافت/پرداخت، کسری، تسویه با تخفیف/هزینه، ورود اقساط، خرید/فروش جزئی طلا و دلار، کارمزد و میانگین بها، سناریوهای مستقل، مهاجرت/پشتیبان، Undo و تعارض چندپنجره‌ای.
- مرورگر Chromium: کارهای واقعی ثبت/ویرایش/پرداخت، persistence، واحد نمایش، طلا و دلار، چهار سناریو، CSV، تقویم و راهنمای اولیه در دسکتاپ و موبایل.
- axe WCAG 2 A/AA و 2.1 AA روی صفحات نماینده، هر دو تم؛ بررسی اسکرول افقی و viewport تبلت. این بررسی خودکار جای ممیزی دستی کامل WCAG را نمی‌گیرد.
- build تولید و TypeScript strict؛ فایل‌های خصوصی و خروجی‌ها وارد Git نمی‌شوند.

## محدودیت‌های صریح

- خدمات آنلاین نرخ، اتصال رسمی اعتباردهنده و همگام‌سازی چند دستگاه پیاده‌سازی نشده‌اند؛ داده مالی به بیرون ارسال نمی‌شود.
- تاریخچه ذخیره‌شده، شرح اقدام‌هاست؛ دفتر حسابرسی تغییرناپذیر نیست. Undo فقط آخرین اقدام را بازمی‌گرداند.
- سناریوها فرضی‌اند؛ ترتیب درون‌روز، تورم و ریسک‌های بازار پیش‌بینی نمی‌شوند. خرید پلکانی در پایان ماه و تغییر درصد قیمت خطی است.
- تسویه به مبلغ اعلام‌شده برای همه اقساط باقی‌مانده قرارداد است؛ پرداخت قسط خاص از دفتر انجام می‌شود. الگوریتم تشخیص خودکار تخفیف یا شروط اعتباردهنده وجود ندارد.
- گزارش بودجه در بازه دلخواه، مبلغ واقعی بازه را نشان می‌دهد؛ سقف نمایش‌داده‌شده متعلق به یک ماه است و برای بازه چندماهه خودکار ضرب نمی‌شود.
- هدف مالی و اعلان مرورگر از ویژگی‌های اختیاری مشخصات اولیه‌اند و هنوز اضافه نشده‌اند. هشدار نقد و اولویت کاهش اسمی اقساط قابل تنظیم‌اند؛ پرداخت واقعی خودکار نیست.
- موفقیت محلی، موفقیت GitHub Actions یا فعال‌بودن سایت را اثبات نمی‌کند. انتشار به دسترسی و تنظیم Pages وابسته است.

## اصلاحات حاصل از بررسی

جدول عریض پیش‌بینی با صفحه‌کلید قابل پیمایش شد. منوی بلند دسکتاپ پیمایش مستقل دارد. تغییر تم به جای گذار پس‌زمینه با متن نامتناسب، رنگ‌ها را هم‌زمان اعمال می‌کند. قیمت/اصل بدهی نامعلوم با صفر از پیش پر نمی‌شود. ورودی سناریو با Zod کپی عمیق می‌شود تا حتی ارجاع اشتراکی آرایه‌ها نیز به تخصیص اقساط اثر نگذارد.

آخرین اجرای کامل: ۴۷ تست واحد/رابط/ذخیره‌سازی و ۱۸ تست مرورگر موفق؛ TypeScript و build موفق. نسخه تولید نیز با مرورگر روی مسیرهای اصلی و بارگذاری chunkها بررسی شد و خطای اجرا یا HTTP asset مشاهده نشد. تصاویر واقعی دسکتاپ/موبایل/تبلت در test-results ساخته می‌شوند و به Git نمی‌روند.
