# CHEGHAD | چقدر؟
نسخه تکمیل‌شده بر مبنای ZIP ارسالی کاربر؛ داده مالی پیش‌فرض ندارد. درآمدهای مورد انتظار از نقد واقعی جدا هستند و خرید/فروش طلا و دلار مستقل محاسبه می‌شوند.

## اجرا
Node.js 24:
```sh
npm ci
npm run dev
npm run check
```
برای خروجی Pages:
```sh
GITHUB_PAGES=true npm run build
GITHUB_PAGES=true npm run preview
```

ثبت درآمد، هزینه یا قسط از بخش مربوط انجام می‌شود؛ «ثبت پرداخت/دریافت» رویداد واقعی است. مبلغ خالی نامعلوم است. موجودی افتتاحیه مربوط به قبل از همه پرداخت‌هاست. تنظیم نرخ دارایی، نقد اولیه، ذخیره و بودجه از تنظیمات انجام می‌شود. اطلاعات در IndexedDB می‌مانند؛ JSON خصوصی را برای پشتیبان دریافت کنید.

## Gemini
AI فقط با نشانی بک‌اند امن و ورود معتبر فعال می‌شود. ارسال اطلاعات نیازمند رضایت جداگانه و تغییر مالی نیازمند مشاهده تفاوت و تأیید صریح است. کلید AI Studio فقط Secret سمت سرور است؛ هرگز آن را در UI یا Git نگذارید. Worker نمونه امن آماده بررسی است اما منتشر یا با کلید زنده آزمایش نشده است. پیش از راه‌اندازی باید Cloudflare Access با issuer/audience و فهرست کاربران مجاز، مبدأهای دقیق CORS و Durable Object سهمیه تنظیم شوند. درخواست فاقد این تنظیمات رد می‌شود.

۲۹ تست مالی/ذخیره‌سازی/امنیت و build اجرا شده‌اند. Gemini در تست‌ها شبیه‌سازی شده؛ این به معنی اتصال زنده نیست. فایل CODEX_NEXT شرح درخواست اولیه است؛ آخرین دستور کاربر بر آن مقدم است. وضعیت جاری در PROGRESS.md است.
